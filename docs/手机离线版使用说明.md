# 手机离线版：测试与手动传数据

## 现在的工作方式

- 手机安装离线版后，事项、项目、习惯和复盘保存在这台手机的浏览器本机数据库中。
- 电脑仍使用原来的本地版本。两端不会自动同步。
- 手机在“设置 → 数据备份”导出 JSON；电脑在“设置 → 数据备份 → 恢复备份”导入。导入会替换电脑当前整份数据，电脑会先保存导入前快照。
- 测试期间建议以手机为主本。若电脑也修改了事项，先保留两端备份，请 Codex 对照合并，避免直接覆盖。

## 你需要做的事

1. 注册或登录免费的 Cloudflare 账号，在 **Workers & Pages → Pages** 新建 **Direct Upload** 项目。
2. 上传项目文件 [mobile-offline-upload.zip](../mobile-offline-upload.zip)，或者直接上传 `dist-mobile` 文件夹。上传的是程序文件，不含个人事项数据。Cloudflare 会给出一个 `pages.dev` HTTPS 网址。
3. 用手机打开该网址。iPhone 建议用 Safari 的“共享 → 添加到主屏幕”；安卓可使用浏览器菜单中的“安装应用／添加到主屏幕”。打开主屏幕图标一次，等页面加载完毕后，再测试断网启动。
4. 若要把电脑当前内容带到手机：电脑端打开“设置 → 导出完整备份”，将 JSON 文件通过隔空投送、数据线或其他你信任的方式放进手机“文件”；然后在手机版“设置 → 恢复备份”选择这个文件。
5. 手机使用一段时间后，点“导出完整备份”或“分享备份文件”，将 JSON 文件保存在手机“文件”并复制到电脑。电脑端用“恢复备份”导入即可。

首次安装时手机需要联网下载程序。安装完成后，手机没有网络或电脑关机时，离线版也能打开和记录。不要清除该网站的浏览器数据；请定期导出 JSON 到手机以外的位置。

## 本地构建与更新

在项目目录执行 `npm run build:mobile`，会生成 `dist-mobile`。每次修改程序后重新构建并重新上传该文件夹；手机本机数据与程序文件分开保存，更新程序不会主动覆盖记录。

免费静态托管说明：[Cloudflare Pages Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)。离线工作原理：[MDN 离线网页应用](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation)。
