# 六维人生管理系统

项目、行动、习惯和复盘的个人管理工具，提供电脑本地版与手机离线版。

## 手机离线版

手机首次加载后，可在电脑关机时使用。两端数据独立，通过 **设置 → 导出完整备份 / 恢复备份** 手动传递 JSON；恢复是整份替换，不会自动合并。个人数据、备份和本地文档不进入源码仓库。

## 本地运行

需要 Node.js 22。

```bash
npm ci
npm run dev -- --hostname 0.0.0.0 --port 3040
```

电脑打开 `http://127.0.0.1:3040/`。

## 检查和手机构建

```bash
npm run typecheck
npm test
npm run build:mobile
```

静态构建结果在 `dist-mobile`。更多说明见 [手机离线版使用说明](docs/手机离线版使用说明.md)。
